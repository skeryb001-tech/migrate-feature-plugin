# 高频故障兜底手册

只读取与当前症状对应的章节。先停止扩大改动，再回到最早受影响的流程步骤；修复后只重跑相关检查及受影响消费者回归。

## 统一止损

1. 保存失败命令、日志、请求/bridge、截图或 diff。
2. 区分源基线问题、目标既有问题和本次迁移新增问题。
3. 找到最小复现输入和第一个偏离源行为的位置。
4. 回到“范围、映射、实现、验证”中最早出错的一步修复。
5. 若涉及数据、安全、权限、生产配置、不可逆写入、同名覆盖或未授权公共契约变更，停止写入并将结论标记为 `BLOCKED`。

## 1. 同名文件、路径或自动发现冲突

- 先判断职责是否等价；等价时复用或最小合并，不等价时保留目标文件并语义化重命名迁入实现。
- 同步更新静态/动态导入、barrel export、自动注册、路由、types、tests 和 assets 引用。
- 仅对实际迁入路径运行 `scanMigrationConflicts.py`，不要用全仓扫描替代职责判断。

## 2. 目标已有能力与源契约不等价

- 对比输入、输出、默认值、错误、异步时序和副作用次数，确认差异发生在目标能力还是调用方。
- 优先添加最窄适配层；不要复制一套平行基础设施，也不要为复用而改变源业务语义。
- 修改共享能力前列出消费者并验证兼容；无法兼容且没有授权时标记 `BLOCKED`。

## 3. API、鉴权、权限或数据结构不一致

- 从 UI 入口追到实际请求/bridge，比较方法、字段、序列化、鉴权、响应解析和错误映射。
- 字段差异收敛在类型明确的边界适配器；不要把兼容逻辑散落到 UI。
- 涉及支付、额度、权限、生产写入或持久化 schema 时，先用只读或隔离环境证明契约，再允许真实写入。

## 4. 重复请求、订阅、计时器、写入或埋点

- 找到唯一职责所有者，检查 mount/appear、watcher、导航回调、重试和恢复路径是否重复触发。
- 为请求和副作用记录触发边缘、次数、取消与清理；在离开、销毁、进入后台或业务 id 变化时释放。
- 使用 Network、IPC 日志、spy 或事件记录验证次数，不以代码形态推断。

## 5. 状态串页、刷新丢失或生命周期异常

- 区分组件私有、页面/视图私有、会话共享和全局状态，按业务 id、用户或会话隔离。
- 对齐初始化、参数变化、再次进入、刷新/重启恢复、前后台和进程重建。
- 只持久化耐久且可序列化的数据；验证 A→B、B→A、直接入口和快速切换中的适用路径。

## 6. UI、i18n、自适应或无障碍偏差

- 先固定数据、设备/视口、scale、主题、语言和字体，再比较结构、几何和最终渲染样式。
- 优先修布局模型、容器约束和 token 映射，再处理局部数值；不要用无边界像素补丁追赶截图。
- 覆盖实际存在的加载/空/失败/禁用、hover/focus/pressed、弹层、长文案、安全区、键盘和 reduced-motion 状态。

## 7. 依赖、构建、旧引用或性能问题

- 保留目标包管理器、锁文件和构建基础设施为唯一实现；依赖变化未授权时停止。
- 从第一个真实错误修复路径大小写、导出、代码生成、targets 和残留引用，不用批量改写掩盖根因。
- 性能退化时用相同输入比较请求次数、渲染次数、bundle、内存或冷启动，优先修重复工作和生命周期泄漏。

## 8. 源/目标运行时不可用或脏工作区干扰

- 保存环境、版本、启动命令和原始错误；先判断是否能用替代入口验证相同契约。
- 静态测试、自定义 renderer 或设计稿不能替代用户要求的真实 Browser、App Window/WebView、模拟器/仿真器或真机证据。
- 必需运行时不可用但代码级证据有效时使用 `CODE_ONLY`；不要回滚目标已有改动，也不要把既有检查错误归因于迁移。

## 9. 混合或原生客户端专项失败

- IPC/bridge：核对 channel/command、payload、序列化、权限、context isolation、取消和销毁后清理。
- 导航/生命周期：核对 push/pop/modal/deep link、前后台、进程重建、线程/协程取消和主线程 UI 更新。
- 平台适配：核对 safe area、状态/导航栏、键盘、旋转、密度、字号、RTL、无障碍、ABI、架构、签名和 release 构建中的适用项。
